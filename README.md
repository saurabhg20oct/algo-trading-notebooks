# algo-trading-notebooks

ServLoci's 24-part Colab course plus a standalone Dhan quickstart — see
[`notebooks/README.md`](notebooks/README.md) for the full index. It covers
18 documented Indian broker APIs, 50 technical indicators, normalized broker
candles, alerts, risk checks and static-IP order dispatch through
[comm.servloci.in](https://comm.servloci.in).

Quick start: [open the tested Dhan + trading-static-ip notebook in Google Colab](https://colab.research.google.com/github/ivikasavnish/algo-trading-notebooks/blob/main/notebooks/colab_dhan_trading_static_ip.ipynb).

New learning path: [compare broker APIs](notebooks/20_indian_broker_api_landscape.ipynb)
→ [compute 50 indicators](notebooks/21_top_50_technical_indicators.ipynb)
→ [connect broker candles](notebooks/22_broker_data_indicator_pipeline.ipynb)
→ [generate alerts and dry-run dispatch](notebooks/23_alerts_and_servloci_dispatch.ipynb).
