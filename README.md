# algo-trading-notebooks

ServLoci Colab notebook series (36 parts + Dhan quickstart) — see
[`notebooks/README.md`](notebooks/README.md) for the full index.

Open any notebook in Colab from the badge at the top of the file, or browse
the rendered copies at [comm.servloci.in/notebooks](https://comm.servloci.in/notebooks/).
Chapters 21 and 24–35 run on public `yfinance` data (35 also uses Prophet and
optional Google Drive). Broker chapters use a dedicated static IPv6 + SOCKS5
proxy from [comm.servloci.in](https://comm.servloci.in).
